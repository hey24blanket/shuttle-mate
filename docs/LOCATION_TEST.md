# 실제 위치 추적 테스트 — v1.2

## 시작

1. 같은 휴대폰 브라우저에서 https://shuttle-mate.vercel.app/driver 를 연다.
2. **내 위치 추적 시작**을 누른 뒤 브라우저의 위치 권한 요청을 허용한다. 정밀 위치 선택이 있다면 사용한다.
3. **실제 위치** 지도에 파란 점이 나타나는지 확인한다. 지도 아래 좌표·정확도·갱신 시각을 확인한다.
4. 실내에서 정확도가 나쁘면 하늘이 보이는 안전한 곳에서 기다린다. 정확도 100m 초과는 오차 안내를 표시한다.

## 이동과 역할 전환

1. 운전하지 말고 안전한 곳에서 30~100m 걸으며 지도와 좌표가 바뀌는지 확인한다.
2. 지도를 드래그하면 자동 따라가기를 해제한다. **내 위치로 이동**을 누르면 다시 따라간다.
3. 같은 탭에서 학부모 → 운영자로 전환한다. 같은 좌표가 보이며, 계속 이동하면 갱신된다.
4. 예시 노선을 누르면 기존 가상 운행을 볼 수 있다. 실제 GPS 이동만으로 정차지가 넘어가거나 도착 시간이 계산되지는 않는다.

## 중단과 복구

- **추적 중지**: 모든 역할에서 현재 위치 표시가 사라지고 기기에 보관한 좌표가 삭제되어야 한다.
- **권한 거부**: 가짜 현재 위치를 보여주지 않고 권한을 켜라는 안내가 나온다. 사이트 위치 권한과 OS 위치 서비스를 켠 뒤 다시 시작한다.
- **화면을 벗어남/잠금**: 화면이 숨겨지면 추적을 일시 중지한다. 같은 페이지로 돌아오면 추적을 재개한다. OS가 앱을 종료했거나 새로고침한 경우에는 시작 버튼을 다시 누른다.
- **일시적 오류**: 수신 불가/시간 초과를 표시하며 다음 정상 위치를 받으면 복구한다. 마지막 좌표가 남으면 현재 위치로 단정하지 않도록 회색 점으로 표시한다.
- **갱신 지연**: 30초 이상 새 좌표가 없으면 마지막 위치임을 표시한다. 정지 중이거나 기기 환경에 따라 새 좌표 수신 간격은 달라진다.
- **운행 종료/취소/체험 초기화**: 위치 감시를 해제하고 이전 위치를 제거한다. 새 운행에서는 직접 시작한다.
- **지도 오류**: 인터넷 연결이 없으면 지도 배경을 받지 못할 수 있다. 좌표와 정확도는 별도로 확인할 수 있다.

## 위치 사용 범위

현재 위치 1건만 이 브라우저에 보관한다. 이동 이력은 수집하지 않는다. 위치를 별도 서버/Firebase에 전송하지 않는다. 같은 브라우저의 탭에는 반영되지만 다른 휴대폰이나 다른 브라우저와는 공유하지 않는다. 새 탭으로 이동하면 위치를 수신하던 원래 탭이 숨겨져 일시 중지될 수 있으므로 **한 탭에서 상단 역할 버튼으로 전환하는 방식**을 권장한다.

지도는 Leaflet + OpenStreetMap을 사용한다. 화면에 보이는 지역의 지도 타일을 OpenStreetMap 서버에서 받으므로 지도 제공자는 요청된 지도 영역을 알 수 있다. 대규모 실서비스 전환 시 SLA가 있는 지도 제공자와 인증된 기기 간 위치 동기화를 추가한다.

## 개발 검증

브라우저 테스트에서는 실제 Geolocation API를 Chrome의 지정 좌표로 시험한다. 물리적인 휴대폰 GPS 정확도, 실제 보행/주행 경로와 iOS/Android의 배터리·백그라운드 동작을 대신 검증하는 것은 아니다.
